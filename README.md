# merge-sorted-arrays

Merge 3 sorted int arrays into one ascending array, without using any sort function.

Input:
 collection_1: sorted max -> min
 collection_2: sorted min -> max
 collection_3: sorted min -> max

## Setup

```
npm install
```

Tested on Node 18.

## Run tests

```
npm test
```

## Run the demo

```
npm start
```
